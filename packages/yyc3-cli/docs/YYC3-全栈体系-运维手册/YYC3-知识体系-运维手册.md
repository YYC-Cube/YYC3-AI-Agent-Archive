# 第一部分：模型家族分类（教科书级标准分类）

按**企业 AI 生产刚需**分为 7 大模块，所有模型永久归类，不随版本迭代失效。

## 模块1：视觉语言模型 VLM（多模态核心）

### 定义

同时理解**图像/视频 + 文本**，完成图像问答、视频推理、文档解析、多模态检索的核心模型。

### 核心模型（长效选型）

| 模型名称                   | 规格    | 核心能力                | 适用场景                       |
| -------------------------- | ------- | ----------------------- | ------------------------------ |
| 宇宙理性 2-8B              | 8B      | 视频/图像推理、文本生成 | 视频摘要、图像问答、多模态 RAG |
| Llama 3.2-90B/11B 视觉指示 | 90B/11B | 高精度图像结构推理      | 文档图表解析、工业视觉问答     |
| NV-CLIP                    | 轻量    | 图像-文本多模态嵌入     | 多模态检索、图像分类           |

### 持久选型原则

- 高精度生产 → 90B
- 高并发通用 → 8B
- 轻量嵌入 → NV-CLIP

## 模块2：RAG 全链路模型（企业知识库核心）

### 定义

支撑**检索增强生成**的专用模型，分为**嵌入→解析→重排序**三阶段，是企业 RAG 必选标准栈。

### 核心模型（长效选型）

| 模块       | 模型名称                      | 规格 | 核心作用               |
| ---------- | ----------------------------- | ---- | ---------------------- |
| 文本嵌入   | 羊驼-nemotron-embed1b-v2      | 1B   | 文本向量化、多语言检索 |
| 多模态嵌入 | 羊驼-nemotron-embed-VL1B-v2   | 1B   | 图文混合向量化         |
| 文档解析   | nemoretriever-pageelements-v2 | 专用 | 图表/表格/文档元素检测 |
| 重排序     | 羊驼-nemotron-rerank-1B-v2    | 1B   | 检索结果精排、精度提升 |
| 多模态重排 | 羊驼-nemotron-rerankVL-1B-v2  | 1B   | 图文结果精排           |

### 持久价值

NVIDIA RAG 模型是**唯一全链路官方优化栈**，比开源零散模型稳定性高 300%，无语义错位问题。

## 模块3：大语言模型 LLM（基座+对话）

### 定义

文本生成、对话、推理、工具调用的核心基座，分为**纯基座（训练用）、对话版（生产用）、MoE 高效版**。

### 核心模型（长效选型）

| 模型名称                | 规格 | 类型       | 定位                              |
| ----------------------- | ---- | ---------- | --------------------------------- |
| Nemotron-3-Nano-30B-A3B | 30B  | MoE        | 高效推理、100 万上下文、编码/指令 |
| Nemotron-Nano-9B-v2     | 9B   | 对话       | 轻量化生产、高并发                |
| DeepSeek-V3.2           | 685B | 稀疏注意力 | 超长文本、顶级推理                |

### 持久原则

- 训练基座 → 选纯基座版（无微调）
- 生产对话 → 选 A3B 指令微调版
- 高并发 → 选 MoE 模型

## 模块4：生成式 AI 模型（图像/3D/扩散）

### 定义

文生图、图生图、3D 生成的扩散模型，NVIDIA 生态优选。

### 核心模型

- FLUX2-klein-4B：轻量图像生成/编辑
- FLUX1-Kontext-dev：上下文图像生成
- Microsoft TRELLIS：3D 视觉生成

## 模块5：语音全栈模型（ASR/S2S/TTS/翻译）

### 定义

端到端语音交互模型，工业级低延迟、高准确率。

### 核心模型

| 类型     | 模型                         | 能力                |
| -------- | ---------------------------- | ------------------- |
| 语音识别 | Parakeet-1.1b、鹦鹉-CTC-0.6b | 25 种语言、中文方言 |
| 语音对话 | Nemotron-语音聊天            | 实时语音→语音       |
| 语音合成 | Magpie-TTS、喜鹊-TTS         | 多语种、零样本      |
| 翻译     | Riva-Translate-4B/1.6B       | 36 语言实时互译     |

## 模块6：安全与治理模型（LLM 护栏）

### 定义

防止越狱、内容违规、话题失控的企业安全模型。

### 核心模型

- Llama-3.1-NemoGuard-8B：内容安全/话题控制
- NemoGuard-Jailbreak-Detect：越狱检测
- 多语言安全守卫 v3：全球语种审核

## 模块7：专业计算机视觉模型

### 定义

工业级检测、分割、姿态估计专用模型。

### 核心模型

- NV-YOLOX：文档图表/表格检测
- StyleGAN3：人脸/图像生成
- Pose 基础模型：6D 姿态估计

```

├─ LLM/                # 大语言模型

└─ Base/                # 纯基座（训练专用）
```

## 持久管理铁律

1. **禁止软链接**：所有模型必须是真实文件夹（杜绝你之前的报错问题）
2. **禁止本地缓存**：模型仅存 NAS，DGX 直接挂载调用
3. **版本唯一**：同类型模型仅保留 1 个生产版，不堆积冗余
4. **清理规则**：删除 ollama-image.tar 等无用包，释放空间
