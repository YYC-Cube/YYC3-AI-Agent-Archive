# NVIDIA-DGX-Skil

001. **accelerated-computing-cudf**
         GPU加速计算cuDF数据处理技能，提供与Pandas兼容的DataFrame操作能力。用于大规模结构化数据的高性能清洗、转换、聚合与分析场景，可直接在GPU上执行数据运算，大幅提升数据处理效率。

002. **aiq-deploy**
         NVIDIA AI-Q Blueprint基础设施部署技能。用于安装、部署、运行、验证、故障排查或停止整套NVIDIA AI-Q基础设施环境的全流程操作。

003. **aiq-research**
         NVIDIA AI-Q研究探索技能，用于AI-Q相关的算法调研、实验设计、基准测试与技术方案验证，支撑AI-Q领域的前沿研究与原型验证工作。

004. **cudaq-guide**
         CUDA-Q量子计算编程指南技能。用于解答CUDA-Q框架的安装配置、语法使用、编程范式与调试问题，提供量子-经典混合计算的开发指引。

005. **cufolio**
         基于cuOpt的投资组合优化专用技能，支持金融投资组合的收益风险建模、约束条件配置与高效求解，可快速输出最优资产配置方案。

006. **cuopt-developer**
         cuOpt开发者进阶技能，用于cuOpt的源码构建、深度定制开发、底层功能调试与二次开发场景，提供cuOpt内部架构与开发流程的专业指引。

007. **cuopt-install**
         cuOpt安装部署技能，支持通过pip、conda、Docker等方式为Python、C语言或服务端安装cuOpt并验证安装状态，源码构建场景需使用cuopt-developer。

008. **cuopt-numerical-optimization-api-c**
         cuOpt数值优化C语言API技能，支持通过C/C++接口调用cuOpt求解线性规划、混合整数线性规划与测试版二次规划问题，适用于C/C++工程嵌入数值优化能力的场景。

009. **cuopt-numerical-optimization-api-cli**
         cuOpt数值优化命令行接口技能，支持通过命令行读取MPS文件并求解线性规划、混合整数线性规划与测试版二次规划问题，适用于快速批量求解优化任务。

010. **cuopt-numerical-optimization-api-python**
         cuOpt数值优化Python API技能，支持通过Python接口求解线性规划、混合整数线性规划与测试版二次规划问题，覆盖调度、投资组合、最小二乘等业务场景。

011. **cuopt-numerical-optimization-formulation**
         cuOpt数值优化建模技能，讲解线性规划、混合整数线性规划、二次规划的核心概念、问题解析方法与建模范式，仅覆盖领域知识，不涉及具体API操作。

012. **cuopt-routing-api-python**
         cuOpt路径规划Python API技能，基于cuOpt实现车辆路径规划、旅行商问题、取派件问题的求解，仅支持Python接口，适用于Python环境下的路径规划业务开发。

013. **cuopt-routing-formulation**
         cuOpt路径规划建模技能，讲解车辆路径规划、旅行商问题、取派件问题的问题类型、数据需求与领域概念，不涉及具体API与接口实现。

014. **cuopt-server-api-python**
         cuOPT REST服务端Python接口技能，提供cuOPT REST服务器的启动、端点调用、Python/curl客户端示例，适用于部署与调用cuOPT服务端API的场景。

015. **cuopt-server-common**
         cuOPT REST服务端通用概念技能，讲解cuOPT REST服务器的核心功能、请求流转逻辑与领域概念，不涉及具体部署操作与客户端代码实现。

016. **cuopt-skill-evolution**
         cuOpt技能迭代演进技能，用于cuOpt相关技能的版本更新、能力升级、功能迭代与适配优化，跟踪cuOpt技能体系的演进路径与变更说明。

017. **cuopt-user-rules**
         cuOpt用户使用规则技能，定义终端用户调用cuOpt路径规划、数值优化、服务端能力的基础规范与边界，不适用于cuOpt内部组件的开发调试。

018. **cupynumeric-hdf5**

019. **cupynumeric-install**

021. **cupynumeric-parallel-data-load**
