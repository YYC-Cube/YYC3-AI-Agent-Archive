# YYC³ Agent 设计规范

## Agent 四大内核

| 内核 | 定义 | 职责 |
|------|------|------|
| **感知内核** | 环境感知与输入理解 | 语义解析、意图识别、实体抽取、上下文管理 |
| **决策内核** | 任务规划与资源调度 | 任务拆解、路径规划、Skill 匹配、优先级决策 |
| **执行内核** | 原子能力调用与结果输出 | Skill 调用、参数填充、结果格式化、异常处理 |
| **记忆内核** | 状态持久化与知识沉淀 | 会话记忆、知识检索、经验积累、长期记忆 |

## 五层解耦架构

```
┌─────────────────────────────────────────────┐
│  接入层 (Entry Layer)                        │
│  职责: 统一入口、请求校验、身份认证          │
├─────────────────────────────────────────────┤
│  编排层 (Orchestration Layer)               │
│  职责: 任务编排、上下文管理、状态追踪        │
├─────────────────────────────────────────────┤
│  能力层 (Capability Layer)                  │
│  职责: Skill 调用、工具使用、模型推理        │
├─────────────────────────────────────────────┤
│  知识层 (Knowledge Layer)                   │
│  职责: RAG 检索、知识库、向量存储            │
├─────────────────────────────────────────────┤
│  基础设施层 (Infrastructure Layer)          │
│  职责: MCP 通信、日志、监控、安全审计        │
└─────────────────────────────────────────────┘
```

## Agent 与 Skill 的关系

- **Agent**：负责决策「做什么、什么时候做」— 四大内核驱动
- **Skill**：负责「怎么做、执行出结果」— 原子能力单元
- Agent 通过 MCP 标准协议调用 Skill，二者完全解耦
