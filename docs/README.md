## 🚀 快速入口（按角色推荐）

| 角色 | 推荐阅读顺序 | 核心关注点 |
| ---- | ------------ | ---------- |
| **架构师** | 九层架构 → 多智能体架构 → 五维驱动 → 多租户设计 | 技术蓝图与架构决策 |
| **Agent 开发者** | Agent 设计规范 → 系统提示词 → Skill 核心定位 → 降级熔断标准 | 角色定义与能力调用 |
| **Skill 开发者** | Skill 核心定位 → Skill 安全审计 → 开发标准 | 标准模板与全生命周期 |
| **前端开发者** | 功能拆解指南 → 开发标准 → 多端适配规范 | 组件化与独立开发 |
| **QA / 测试** | 全局验收标准 → 测试审核验收 → 安全加固 → 混沌工程 | 质量保障与闭环 |
| **运维 / DevOps** | 九层架构(基础设施) → 验收系统 → 混沌工程演练 | 部署与可观测性 |
| **项目管理者** | 五维驱动 → 文档闭环 → 全局验收标准 → 落地路线图 | 度量与里程碑 |
