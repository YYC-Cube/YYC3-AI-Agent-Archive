# YYC³ 第三方 Skill 安全审计流程

## 一、设计原则

第三方 Skill 是 YYC³ 生态化能力建设的关键一环，但同时也带来安全风险。本规范定义「四步审核 + 灰度发布」的标准化安全审计流程，在保障生态开放性的同时守住安全底线。

| 原则 | 说明 |
| ---- | ---- |
| **最小权限** | 第三方 Skill 默认无权限，按需申请、按次授权 |
| **沙箱隔离** | 所有第三方 Skill 在沙箱环境中运行，不得访问核心系统资源 |
| **全链路留痕** | 每次调用全量记录入参、出参、执行日志，支持追溯 |
| **渐进放开** | 从 10% 流量开始灰度，逐步放大至 100% |
| **一键熔断** | 发现风险可即时下架 Skill，阻断所有调用 |

## 三、各步骤详细标准

### 3.1 第一步：自动安全扫描

| 检测项 | 检测内容 | 通过标准 |
| ------ | -------- | -------- |
| 静态代码审计 | 检查代码安全漏洞、后门、硬编码密钥、危险函数调用 | 零高危漏洞 |
| 依赖组件扫描 | 生成 SBOM，检测已知漏洞依赖 | 无 Critical 级别 CVE |
| 敏感信息检测 | API Key、密钥、内网地址、隐私信息泄露 | 零泄露 |
| 权限需求分析 | 评估 Skill 申请的权限是否与其功能匹配 | 权限最小化原则 |

**工具链**：SonarQube + Trivy + 自研敏感信息检测引擎

### 3.2 第二步：沙箱隔离测试

| 测试项 | 测试场景 | 通过标准 |
| ------ | -------- | -------- |
| 功能一致性 | 验证 Skill 功能与描述一致，不包含隐藏行为 | 100% 功能匹配 |
| 性能基准 | 500ms 以内响应率 ≥ 99%，最大不超 3s | P50 < 500ms |
| 异常路径 | 非法入参、超长输入、并发高负载 | 不崩溃、不泄露信息 |
| 资源消耗 | CPU/内存/网络使用是否在合理范围 | 不超出基线 200% |

**沙箱环境**：独立 Kubernetes Namespace + 网络隔离 + 存储隔离

### 3.3 第三步：智云·守护人工复审

| 审查维度 | 审查项 | 判定标准 |
| -------- | ------ | -------- |
| 行为合规 | Skill 行为是否与描述一致，是否存在越权行为 | 无违规行为 |
| 数据安全 | 处理的数据类型、存储位置、是否涉及敏感数据 | 符合数据分级规范 |
| 品牌合规 | 输出内容是否包含竞品信息、品牌负面表述 | 零品牌违规 |
| 风险等级 | 综合判定：低/中/高三个风险等级 | 低风险自动放行 |

**风险等级对应处置**：

| 风险等级 | 处置策略 | 调用限制 |
| -------- | -------- | -------- |
| **低风险** | 自动放行 | 不限 |
| **中风险** | 限制调用频次 + 限定 Agent | 100次/h, 限3个Agent |
| **高风险** | 仅限白名单 Agent + 二次确认 | 10次/h, 限1个Agent, 每次人工确认 |

### 3.4 第四步：灰度发布

| 阶段 | 流量比例 | 时长 | 验收指标 | 回滚条件 |
| ---- | -------- | ---- | -------- | -------- |
| Phase 1 | 10% | ≥24h | 成功率≥99%, P50<500ms, 零安全事件 | 任意指标不达标 |
| Phase 2 | 50% | ≥24h | 成功率≥99%, 零安全事件 | 安全事件触发 |
| Phase 3 | 100% | 正式发布 | 连续 7 天无异常 | 运维可手动回滚 |

## 四、全生命周期安全管理

### 4.1 上架后持续监控

| 监控项 | 频率 | 告警阈值 |
| ------ | ---- | -------- |
| 调用成功率 | 实时 | < 95% |
| 平均响应时延 | 实时 | > 2s |
| 异常输出率 | 实时 | > 1% |
| 安全事件 | 实时 | 任意事件触发 |
| 调用量突增 | 每小时 | > 基线 5x |
| 资源使用趋势 | 每天 | 持续上升 > 7 天 |

### 4.2 下线机制

| 触发条件 | 处置动作 | 通知时效 |
| -------- | -------- | -------- |
| 发现高危安全漏洞 | 立即熔断下架 | 即时通知 |
| 连续 7 天调用量 < 10 | 标记为「低活跃」 | 周报 |
| 连续 30 天调用量 = 0 | 自动归档下线 | 下架前 7 天通告 |
| 开发者主动申请下线 | 走下线流程 | 即时处理 |

## 五、紧急响应流程

```
安全事件触发
    │
    ▼
┌────────────────────┐
│  智云·守护判定      │ ◄── 自动/人工触发
│  risk_level: high  │
└────────┬───────────┘
         │
         ▼
┌────────────────────┐     ┌────────────────────┐
│  自动熔断下架       │     │  保留现场证据       │
│  阻断所有调用       │     │  全量日志导出       │
└────────┬───────────┘     └────────┬───────────┘
         │                          │
         └──────────┬───────────────┘
                    ▼
┌────────────────────────────────────┐
│  安全事件复盘（SLA: 24h 出报告）    │
│  根因分析 → 影响面评估 → 改进措施  │
└────────────────────────────────────┘
```
