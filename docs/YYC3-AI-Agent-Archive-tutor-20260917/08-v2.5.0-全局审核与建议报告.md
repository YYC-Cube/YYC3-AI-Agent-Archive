## 四、建议路线（v2.6.0+ 演进）

### P1（建议下版本采纳）

1. **Dependabot vendor 目录豁免固化**：`.github/dependabot.yml` 显式声明 ignore 规则（参考资产目录），从「事后 dismiss 脚本」升级为「事前不告警」——当前 dismiss 是一次性操作，新告警仍会涌入
2. **doctor 增第五检 — example build**：将 vite-react-zh-cn 构建并入 doctor（当前在 CI quality job 独立步骤），本地即可捕获 API 漂移
3. **评分基线随版本自动推进**：release workflow 中自动执行 `gen-baseline-v{N}.cjs` + 更新 doctor GATES.baseline 路径，消除手工改路径环节

### P2（季度内）

4. **doctor --json 接入 GitHub Job Summary**：`$GITHUB_STEP_SUMMARY` 输出 Markdown 表格，门禁可视化
5. **技能资产 D 级清零计划**：当前 D:1（基线内），按 score-report worst 清单定向治理，目标 v2.6.0 基线 D:0
6. **esbuild postinstall 白名单**：example `pnpm approve-builds` 固化到 package.json `pnpm.onlyBuiltDependencies`，消除 CI 安装警告

### P3（长期）

7. **评分维度扩展**：引入「关联维度」（跨技能引用图谱），对齐五维驱动评估框架
8. **doctor 门禁分档**：`--strict`（当前）/ `--advisory`（仅报告）双模式，支持灰度接入新检查
