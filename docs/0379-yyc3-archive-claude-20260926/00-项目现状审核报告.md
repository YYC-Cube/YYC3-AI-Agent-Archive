- **安全工程高于社区平均**：fail-closed 认证（未配 key 返回 503 而非放行）、`timingSafeEqual` 长度均衡时序防护、XFF 受信跳数模型、chunked 流式计数限流、Lua 原子令牌桶、安全头全套（CSP `default-src 'none'`）

### 3.5 观察项（P2）

- `observability/tracer.ts:25` spans Map 无界增长（长期运行泄漏）
- `mcp-runtime/cowagent-bridge.ts:255` Python 子进程全量透传 `process.env`，凭据泄露面过大
- 输出截断「字符 vs 字节」单位混用（registry executor.ts:389-400 与 sandbox executor.ts:51-68 同源）
- `store/file-store.ts:119` flush 竞态（写入不丢失但破坏"防抖后必落盘"预期）
- `yyc3-cli/doctor.js:17` ROOT 路径强耦合 monorepo 结构，npm 全局安装后部分检查失效
- `loader.ts` 全同步 fs 扫描 8,600+ 资产阻塞事件循环 × gateway `POST /reload` 同步调用 = 请求路径卡顿组合
