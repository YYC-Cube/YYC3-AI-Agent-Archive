## 一、本版本核心内容（发布说明素材）

### 主题：Docker 生产就绪全链路闭环

本版本使平台从「本地能构建」进化为「可交付的容器化服务」，并打通 **代码 → 镜像 → 冒烟验证 → 制品仓库** 的全自动发布流水线。

### 1. 新增 ✨

- **三服务独立 HTTP 入口**（此前为纯库包，容器无真实进程可运行）
  - `@yyc3/skill-gateway@1.1.0`：`src/server.ts` 组装 registry/loader/executor 并启动
  - `@yyc3/mcp-runtime@1.2.0`：Hono 暴露 `/health`、`/api/v1/tools`、`/api/v1/tools/call`

  - buildx 构建 3 镜像（gha 缓存 scope 隔离，二次构建提速）
  - compose 启动三容器 → healthy 等待（90s 超时+日志转储）→ **8 项 API 冒烟断言**
  - **冒烟全过才推送** `ghcr.io/yyc-cube/yyc3-ai-agent-archive/*:{tag,latest}`
- **GHCR 镜像发布**：首次提供官方容器制品，`docker compose pull` 即可部署

## 二、发布前必读的两个风险 ⚠️

> 实测 `npm view` 与本地 `package.json` 比对得出，**不处理必定发布失败**。

### 风险 1：9 个包本地版本已与 npm registry 持平 → EP409 冲突

`pnpm publish -r` 会发布**所有非 private 包**，版本与 registry 相同时 npm 返回 `EP409 cannot publish over previously published version`，**整个 Publish job 失败**。

| 包名 | registry 现状 | 本地现状 | 结论 |
| --- | --- | --- | --- |
| @yyc3/skill-registry | 1.1.0 | 1.1.0 | 🔴 必须先 bump |
| @yyc3/mcp-runtime | 1.1.0 | 1.1.0 | 🔴 必须先 bump |
| @yyc3/skill-gateway | 1.0.0 | 1.0.0 | 🔴 必须先 bump |
| @yyc3/agent-runtime | 1.0.0 | 1.0.0 | 🔴 必须先 bump |
| @yyc3/skill-sandbox | 1.0.0 | 1.0.0 | 🔴 必须先 bump |
| @yyc3/plugin-marketplace | 1.0.0 | 1.0.0 | 🔴 必须先 bump |
| @yyc3/conductor | 1.0.0 | 1.0.0 | 🔴 必须先 bump |
| @yyc3/orchestrator | 1.0.0 | 1.0.0 | 🔴 必须先 bump |
| @yyc3/observability | 1.0.0 | 1.0.0 | 🔴 必须先 bump |
| yyc3-cli（非 scoped） | 1.1.0 | 2.0.0 | ✅ 已领先，可直接发布 |
| @yyc3/i18n-core | **2.4.2** | **2.4.0** | 🔴 特殊，见风险 2 |

### 风险 2：@yyc3/i18n-core registry 版本（2.4.2）反超本地（2.4.0）

npm publish 会把 `latest` dist-tag 移动到新发布的版本。若直接发布 2.4.0，**registry latest 将从 2.4.2 回退到 2.4.0**，下游 `npm install @yyc3/i18n-core` 会降级——必须 bump 到 **≥2.4.3**。

> 背景说明：2.4.1/2.4.2 并非本仓库发布（版本历史待追溯），但不影响本处置方案的正确性。

## 四、发布操作步骤（按序执行）

### Step 1: 预检清单

```bash
cd /Users/yanyu/YYC-Cube/YYC3-AI-Agent-Archive

# 1.1 工作区干净、main 已同步
git status --short          # 期望：空

# 1.2 基线 CI 绿灯（当前 5ac07bbf 已确认 success）
gh run list --branch main --workflow CI --limit 1

# 1.3 NPM_TOKEN 已配置（v2.2.1 已验证，无需操作）
gh secret list | grep NPM_TOKEN
```

### Step 2: 版本 bump（解决风险 1/2）

```bash
# 2.1 三个服务包 minor
pnpm --filter @yyc3/skill-gateway --filter @yyc3/mcp-runtime --filter @yyc3/agent-runtime \
  exec npm version minor --no-git-tag-version

# 2.2 其余 @yyc3 包 patch（i18n-core 会被 2.4.3 覆盖，见 2.3）
for p in skill-registry skill-sandbox plugin-marketplace conductor orchestrator observability; do
  (cd packages/$p && npm version patch --no-git-tag-version)
done

# 2.3 i18n-core 跨到 2.4.3（防 latest 回退）
(cd packages/yyc3-i18n && npm version 2.4.3 --no-git-tag-version)

# 2.4 根包标志位（private，仅对齐）
npm version 2.3.0 --no-git-tag-version --workspaces-update=false

# 2.5 核对矩阵（对照第三节逐行确认）
for p in skill-registry skill-gateway mcp-runtime agent-runtime skill-sandbox plugin-marketplace conductor orchestrator observability yyc3-i18n; do
  echo "$p -> $(node -p "require('./packages/$p/package.json').version")"
done
node -p "require('./packages/yyc3-cli/package.json').version"   # 期望 2.0.0
```

### Step 3: CHANGELOG 补全

[CHANGELOG.md](file:///Users/yanyu/YYC-Cube/YYC3-AI-Agent-Archive/CHANGELOG.md) 的 `[2.3.0]` 条目**追加**本轮 CI/CD 内容（当前条目只覆盖 Docker 冒烟本体）：

```markdown
- docker-compose.yml 镜像名参数化：${IMAGE_PREFIX:-yyc3}/...:${TAG:-local}，CI 复用刚构建镜像免二次构建
- mcp-runtime 分支覆盖率 72.09% → 86.04%，全门禁提至 75%
- turbo test 缓存禁用，杜绝缓存假绿
```

### Step 4: 提交推送并等待 CI


### Step 5: 打 tag 触发发布 ⚡

```bash

git push origin v2.3.0
```

### Step 6: 监控 Release workflow

```bash
gh run watch $(gh run list --workflow Release --limit 1 --json databaseId --jq '.[0].databaseId')
```

三个 job 并行执行，关注点：

| Job | 内容 | 失败时的第一排查点 |
| --- | --- | --- |
| 发布到 npm | typecheck → test → build → `pnpm publish -r` | EP409（bump 遗漏）/ 403（token 失效） |
| Docker 构建冒烟 + 推送 GHCR | 构建 ×3 → compose 冒烟 → docker push | 冒烟断言失败日志（会自动打印容器 logs） |
| GitHub Release | changelog 生成 + 创建 Release | 极少失败，与权限相关 |

> 允许降级：NPM_TOKEN 缺失时 npm job 跳过发布但保持绿色（本次已配置，不适用）。

## 七、回滚预案 🔥

| 场景 | 操作 |
| --- | --- |
| Docker job 冒烟失败（发布已中断） | 镜像未推送，无需回滚；修复后重新打 tag（删除 `git tag -d v2.3.0` + 远程 tag 后重打，或直接 v2.3.1） |
| npm 包发布后发现问题 | `npm dist-tag add @yyc3/<pkg>@<旧版> latest` 恢复 latest；严重时 72h 内 `npm unpublish` + `npm deprecate` |
| 镜像有问题 | GHCR 删除对应版本（Packages → 版本 → Delete）；latest 回指：重推旧版为 latest |
| GitHub Release 需撤回 | `gh release delete v2.3.0 --yes && git push origin :refs/tags/v2.3.0` |
| 回滚演练命令 | `IMAGE_PREFIX=ghcr.io/yyc-cube/yyc3-ai-agent-archive TAG=v2.2.1 docker compose up -d --no-build`（v2.2.1 无镜像，实际回滚需本地构建历史 commit） |
