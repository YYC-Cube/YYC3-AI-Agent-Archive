## 四、安全评估

### 4.1 敏感信息检查

- [x] 无硬编码真实密钥 — 近期 commit `4eb570ef3` 已移除泄露的 GitHub PAT 和 Brave API Key
- [x] .env 文件已加入 .gitignore — `.env.example` 仅含占位符
- [x] API Key 使用环境变量 — 示例代码中均为 `your-xxx-here` 占位符
- [x] 数据库连接使用加密传输 — 仅配置模板，无真实凭证
- [x] 无硬编码密码 — 所有密码字段均为示例占位符

### 4.2 安全审计发现

**发现 1: 外部示例中的 base64 token**

- 位置: `plugins-hub/official/scientific-skills/reactome-database/references/api_reference.md:257`
- 内容: `token = "MzUxODM3NTQzMDAwMDA1ODI4MA=="`
- 评估: 该 token 为 Reactome 数据库公开 API 示例 token，非敏感凭证，但建议标注为 `"YOUR_TOKEN_HERE"`
- 风险等级: 低

**发现 2: 历史泄露已修复**

- commit `4eb570ef3` 正确移除了 GitHub PAT 和 Brave API Key
- commit `e7522ceee` 补录了密钥泄露应急处置记录
- 建议: 在 GitHub 仓库设置中启用 Secret Scanning 和 Push Protection

### 4.3 安全建议

1. 启用 GitHub Secret Scanning + Push Protection
2. 对所有外部插件的 `SKILL.md` 和 `references/` 进行 token 扫描
3. 在 CI 中集成 `gitleaks` 或 `trufflehog` 进行预提交密钥检测
4. 添加 `SECURITY.md` 文件定义安全漏洞报告流程
5. 定期审查 `_external/` 目录中第三方代码的安全更新
