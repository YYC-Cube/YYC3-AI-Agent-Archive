## 前言：从「资产归档」到「智能平台」的范式跃迁

### 当前定位

YYC³ AI Agent Archive 已成功完成 **Phase 1: 资产归档**，汇聚了业界罕见的 AI Agent 资产规模（600+ 技能、200+ 插件、8 位智能体、1000+ 图标）。但项目目前处于**资产丰富但运行时缺失**的「档案库」阶段。

### 目标愿景

将 YYC³ 从「资产归档仓库」升级为「**企业级 AI Agent 智能平台**」，实现：
- 技能的**可发现、可注册、可调度、可执行**
- 智能体的**可定义、可协同、可编排、可观测**
- 插件的**可插拔、可组合、可评估、可市场**
- 平台的**高可用、高性能、高安全、高扩展、高智能**

### 2.2 架构改进建议

#### 建议 1: 引入 Turborepo 优化构建

**现状**: 使用 `pnpm -r run build` 顺序构建，无缓存。

**改进**:
```json
// turbo.json
{
  "pipeline": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": ["dist/**"]
    },
    "typecheck": {
      "dependsOn": ["^build"]
    },
    "test": {
      "dependsOn": ["build"]
    }
  }
}
```

**收益**: 增量构建、远程缓存、并行执行，构建时间减少 60-80%。

#### 建议 2: 包发布策略优化

**现状**: 所有包配置 `publishConfig.access: "restricted"`，仅发布到 GitHub Packages。

**改进**: 分层发布策略
- `@yyc3/skill-registry` / `@yyc3/mcp-runtime` → npm public（核心运行时）
- `@yyc3/i18n-core` → npm public（已有独立仓库）
- `@yyc3/icons` → npm public（静态资源）
- `yyc3-cli` → npm public（CLI 工具）

**收益**: 扩大生态影响力，降低使用门槛。

#### 建议 3: 引入 API 版本化策略

**现状**: 无 API 版本管理，Skill 接口变更无保护。

**改进**:
```
packages/skill-registry/src/
├── v1/
│   ├── types.ts      # v1 类型定义（稳定）
│   ├── registry.ts   # v1 注册中心
│   └── index.ts      # v1 入口
├── v2/
│   ├── types.ts      # v2 类型定义（新增字段）
│   └── ...
└── index.ts          # 默认导出最新版本
```

```
│                                              │
```

#### MCP Runtime 优化

```
当前: 同步工具注册，单线程执行
目标: 异步工具注册 + 并行执行池

class UnifiedMCPRuntime {
  private toolCache: LRUCache<string, MCPTool>;  // 工具缓存
  private execPool: WorkerPool;                   // 执行线程池
  private circuitBreaker: CircuitBreaker;         // 熔断器

  async callTool(name: string, args: unknown): Promise<MCPToolResult> {
    // 1. 缓存查找（O(1)）
    const tool = this.toolCache.get(name);

    // 2. 熔断检查
    if (this.circuitBreaker.isOpen(name)) {
      throw new CircuitBreakerError(name);
    }

    // 3. 并行执行池
    return this.execPool.execute(tool, args);
  }
}
```

### 5.2 Skill 沙箱执行模型

```typescript
// 技能沙箱 — 安全执行的核心保障
interface SkillSandboxConfig {
  // 执行超时（默认 30s）
  timeout: number; // ms

  // 允许的命令列表（白名单模式）
  allowedCommands: string[];

  // 允许的网络域名
  allowedDomains: string[];

  // 文件系统访问范围
  workspaceRoot: string;
  readOnlyPaths: string[];
  writablePaths: string[];

  // 资源限制
  maxMemoryMB: number;
  maxCPUPercent: number;
}

// 沙箱执行器
class SkillSandbox {
  async execute(skill: UnifiedSkill, input: unknown): Promise<SkillExecutionResult> {
    // 1. 验证 skill 声明的权限
    this.validatePermissions(skill);

    // 2. 创建隔离执行环境（Docker / WASM / process isolate）
    const env = await this.createIsolatedEnv(skill);

    // 3. 注入输入并执行
    const result = await env.execute(skill, input);

    // 4. 清理环境
    await env.cleanup();

    // 5. 审计记录
    await this.audit(skill, input, result);

    return result;
  }
}
```
